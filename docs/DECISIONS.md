# Decisions

Decisions taken without being told to take them, and why. One line each.

If a decision was instructed, it is not here — it is in the commit that made
it. This file exists for the other kind: the judgement calls made while
carrying out an instruction, where six weeks later the reasoning is gone and
only the artefact remains. Including the ones that overrode a number or a rule
someone else supplied, which are marked **override**.

Newest last. Dates are when the decision was made, not when it was written down.

## 2026-09-03 — Locking level 3's common case, ahead of T2.3b

| # | Decision | Why | Lives in |
|---|---|---|---|
| 50 | Built `evaluate_level_3` as a standalone, tested unit before T2.3b exists, rather than waiting to build all six levels together | Explicitly asked for: lock the behaviour of the level that governs the common case (95.4% of addresses have no `install_dates` row) before the surrounding derivation is built, so the contract is fixed and tested before five more levels get written against it. | 52 | An install date on file but **older than 12 months** produces the identical `NO_VERDICT` as no install date at all — not a third, more specific "expired" outcome | docs/DATA.md's precedence table only ever described level 3 firing "labor covered"; it never described a level 3 denial.
